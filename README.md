# Portal Web Star Wars - Vue.js + SWAPI

Este proyecto fue desarrollado por **Diego Coaquira** como parte de la segunda evaluación de la materia de Tecnología Web.

## 📌 Descripción
Se trata de un portal web que muestra personajes del universo Star Wars, consumiendo la API pública [SWAPI](https://swapi.dev/). El sitio fue construido con Vue.js, organizando vistas y componentes reutilizables.

## 🚀 Tecnologías Utilizadas
- Vue.js (Vue CLI)
- Vue Router
- HTML + CSS (Flexbox)
- Fetch API

## 🎯 Funcionalidades
- Vista de inicio y vista de personajes.
- Consumo dinámico de datos desde SWAPI (`https://swapi.dev/api/people`).
- Tarjetas con información de personajes.
- Manejo de errores y estado de carga.

## 🧱 Estructura del Proyecto
- `/components`: Navbar, Card, Footer
- `/views`: HomeView, PeopleView
- `/router`: Configuración de rutas
- `/assets`: Iconos y estilos adicionales
